## Summary
- add a new CLI e2e fixture project `fastify-min` under `packages/cli/test/fixtures/projects/fastify-min`
- add a deterministic CLI e2e test that exercises `tsgodown build` through the rust-adapter boundary, emits `dist-go/main.go`, and verifies stable output hash
- extend the same test to run a real `go mod init` + `go build ./...` compile check when Go toolchain is available

## Why
This locks an end-to-end, reproducible verification path for the fastify-min build flow without touching analyzer/emitter internals.

## Scope safety
- only e2e/integration harness and fixtures were changed
- no analyzer-rust or emitter-go implementation internals were modified
